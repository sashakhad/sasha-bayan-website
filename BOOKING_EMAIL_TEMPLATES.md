# 📧 Booking Email Templates

## Template 1: Information Gathering Email

**Subject:** Show Details Needed - [Event Name] on [Date]

---

Hi [Venue Contact Name],

Thanks for reaching out about having me perform! I'm excited about the possibility of bringing some sitar magic to [Venue Name].

To move forward with booking, I need to gather some details. **You can either reply to this email with the info below, or if it's easier, fill out this quick Google Form: [GOOGLE_FORM_LINK]**

## 🎭 PUBLIC EVENT DETAILS

- **Event Type:** Public event or private gathering?
- **Venue Address:** Full street address (for GPS and promotion)
- **Event Timing:**
  - Doors open time
  - Music/performance start time
  - Event end time
- **Ticketing:** Free event, ticket price, or suggested donation?
- **Age Policy:** All ages, 21+, 18+?
- **Parking:** Available parking info for attendees
- **Special Notes:** Dress code, what to expect, accessibility info

## 🎵 ARTIST/TECHNICAL INFO

- **Payment:** Guaranteed fee amount OR percentage of door/tickets
- **Sound Setup:**
  - PA system available? (speakers, mixer)
  - Microphones provided?
  - Do you have someone to run sound?
- **Load-in:** What time can I arrive and set up?
- **Stage/Performance Area:** Size and setup details
- **Power:** Electrical outlets available near performance area?
- **Day-of Contact:** Name and phone number for event day

## 📱 PROMOTION & LOGISTICS

- **Venue Social Media:** Instagram/Facebook handles for cross-promotion
- **Merchandise:** Space for merch table? (CDs, etc.)
- **Green Room/Artist Area:** Available?
- **Food/Drink:** Provided for artist?

Once I have these details, I can send over a booking confirmation and my payment info page.

Looking forward to creating something beautiful together!

Best,
Sasha Bayan
📧 booking@sashabayan.com
🌐 sashabayan.com

## 📝 GOOGLE FORM STRUCTURE OUTLINE

**Form Title:** Venue Booking Information - Sasha Bayan Performance

### Section 1: Basic Event Info

- Venue name
- Contact person name and email
- Event date (date picker)
- Event type (Public/Private dropdown)
- Full venue address

### Section 2: Event Timing

- Doors open time
- Performance start time
- Event end time
- Load-in time for artist

### Section 3: Audience Details

- Expected attendance
- Age restrictions (dropdown)
- Ticket price or free event
- Parking information

### Section 4: Technical Requirements

- PA system available? (Yes/No)
- Sound engineer available? (Yes/No)
- Microphones provided? (Yes/No)
- Stage/performance area size
- Power outlets near stage? (Yes/No)

### Section 5: Payment & Logistics

- Payment type (Guaranteed fee/Door split/Ticket split)
- Payment amount or percentage
- Day-of contact name and phone
- Special requests or notes

### Section 6: Promotion

- Venue social media handles
- Merchandise table space available?
- Green room/artist area available?
- Food/drink provided for artist?
